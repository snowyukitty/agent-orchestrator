Local profiles

L2 · env-only

For CLIs ai-agent-entrypoint does not manage yet. A profile points the agent at its own state directory (for example CLAUDE_CONFIG_DIR) for that child process only, then you log in inside the session. This is a weaker guarantee than a routed account — and never put an API key or token here; the app rejects them.
