🤖 Agent Accounts

Routed accounts

L1 · routed

Codex accounts resolved by ai-agent-entrypoint, which owns the account manifest and builds each child environment. This app only launches them.

Leave blank to auto-detect a sibling checkout. This stores a machine-local path only.

Local profiles

L2 · env-only

For CLIs ai-agent-entrypoint does not manage yet. A profile points the agent at its own state directory (for example CLAUDE_CONFIG_DIR) for that child process only, then you log in inside the session. This is a weaker guarantee than a routed account — and never put an API key or token here; the app rejects them.

Click an account to start a session.
